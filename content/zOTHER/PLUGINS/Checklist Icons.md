# Kepano's Minimal Theme
Checklist Icons is a snippet from Obsidian Developer Kepano's Minimal Theme. It is built into the minimal theme, but it can be added to other themes that support it by adding it as a css snippet.
The file on the Github repo is a scss. This is a different format from css and it must be converted. I used an online converter and it thankfully just worked. I have this disabled because of the AnuPpuccin theme
- [Github link](https://github.com/kepano/obsidian-minimal/blob/master/src/scss/features/checklist-icons.scss)
